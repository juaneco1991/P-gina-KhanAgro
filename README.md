# KhanAgro

Sitio institucional de KhanAgro desarrollado con Flask. Presenta servicios agronómicos, productos y robótica agrícola en una página responsive.

## Ejecutar en tu computador

1. Instala Python 3.10 o posterior.
2. Abre PowerShell dentro de esta carpeta.
3. Ejecuta:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
flask --app app run --debug
```

4. Abre `http://127.0.0.1:5000` en el navegador.
